# 活性空間の軌道選択（pb2 / pb3 / pb4）

ペロブスカイト・クラスターモデル（Pb×2, Pb×3, Pb×4）の SQD 計算で用いる活性空間
について、**なぜその軌道を選んだのか**をまとめる。可視化用ファイルの作り方も末尾に記す。

関連スクリプト:
- `rebuild_pb_hamiltonian.py` … 本選択でハミルトニアン（hcore, eri, e_nuc）を再構築
- `export_orbitals.py` … 選択軌道を Avogadro 用（Molden / cube）に書き出し
- 参考資料: `Poster1_4.pdf`（活性空間の設計方針の根拠）

---

## 1. 結論（選んだ活性空間）

| 系 | Pb 数 | 活性空間 | 占有活性軌道 | 仮想活性軌道 |
| --- | --- | --- | --- | --- |
| pb2 | 2 | 4e8o  | 正準 HF の上位 **2** 占有軌道（MO 224,225）| **Pb 6p** 伝導帯 **6** 本 |
| pb3 | 3 | 6e12o | 正準 HF の上位 **3** 占有軌道（MO 325–327）| **Pb 6p** 伝導帯 **9** 本 |
| pb4 | 4 | 8e16o | 正準 HF の上位 **4** 占有軌道（MO 404–407）| **Pb 6p** 伝導帯 **12** 本 |

すなわち **Pb 1 個あたり 2e4o（= 占有 1 本 + Pb 6p 仮想 3 本）** を割り当てる。
これはポスターの最小 CAS スケーリング（Pb×1=2e4o → Pb×2=4e8o → Pb×4=8e16o）と一致する。

## 2. なぜこの軌道なのか（物理的理由）

### 2.1 対象は Pb–I の「バンド端」状態
ペロブスカイト太陽電池の光物性（バンドギャップ＝価電子帯上端→伝導帯下端の遷移）を
担うのは **Pb と I の軌道**である。クラスターモデルでは:

- **価電子帯上端（占有側）** = I 5p と Pb のあいだの **Pb–I 相互作用軌道**
- **伝導帯下端（仮想側）** = **Pb 6p**（Pb²⁺ は 6s²6p⁰ なので 6p が空）

したがって「相関に効く最小の軌道群」は **占有 Pb–I 軌道 + 仮想 Pb 6p** となる。

### 2.2 CH₃NH₃（メチルアンモニウム）局在軌道は「傍観者」なので除外
クラスターモデルには有機カチオン CH₃NH₃ が含まれ、その局在軌道がエネルギー的に
**ちょうど HOMO–LUMO 付近に現れる**。特に**正準 LUMO は CH₃NH₃ に局在**しており、
電子相関にもバンド端遷移にも寄与しない。

→ 単純に「エネルギー順で HOMO/LUMO 近傍の窓」を選ぶと、この傍観者軌道を取り込んで
しまい、**相関をほとんど拾えない**（後述の検証で pb2 は SCF とほぼ同じ＝相関 0.6 mHa）。
そこで **軌道の性質（局在）で選別**し、CH₃NH₃ 局在軌道を除外して Pb/I 軌道だけを採る。

### 2.3 占有側＝正準軌道、仮想側＝AVAS で抽出
- **占有側**: 価電子帯上端は正準 HF の上位占有軌道にそのまま現れる（Pb–I 相互作用、
  下表で Pb≈20–25% / I≈75–79%）。よって**正準 HF の上位 N_Pb 占有軌道**を採用。
- **仮想側**: Pb 6p 性は多数の正準仮想軌道に分散しており、エネルギー順では綺麗に
  取り出せない（CH₃NH₃ 軌道と混ざる）。そこで **AVAS（Atomic Valence Active Space）**
  で AO ラベル `Pb 6p` を標的に射影し、**Pb 6p 反結合（伝導帯）を 3·N_Pb 本**抽出する。
  これにより org（有機）成分 ≈ 0.2–0.6% の純粋な Pb 6p 軌道が得られる。

## 3. 定量的な裏付け（軌道ごとの局在 population）

`export_orbitals.py` が出力する Mulliken population（%）。**占有=Pb–I, 仮想=純 Pb 6p,
除外した正準 LUMO=有機局在**であることが数値で確認できる。

### pb2（4e8o）
| # | 役割 | Pb% | I% | org% |
|---|---|---|---|---|
| 1 | 占有 (MO 224) | 21.9 | 77.2 | 0.9 |
| 2 | 占有 (MO 225) | 23.7 | 75.3 | 1.0 |
| 3–8 | 仮想 Pb 6p ×6 | 81.8–84.4 | 15.3–18.2 | 0.0–0.3 |
| 9 | **除外** 正準LUMO (MO 226) | 0.8 | 1.9 | **97.3** |
| 10 | **除外** 正準LUMO (MO 227) | 3.9 | 2.7 | **93.4** |

### pb3（6e12o）
| # | 役割 | Pb% | I% | org% |
|---|---|---|---|---|
| 1–3 | 占有 (MO 325–327) | 20.2–24.5 | 75.0–79.2 | 0.5–0.7 |
| 4–12 | 仮想 Pb 6p ×9 | 79.6–85.8 | 14.0–20.3 | 0.1–0.6 |
| 13 | **除外** 正準LUMO (MO 328) | 2.3 | 2.1 | **95.6** |

### pb4（8e16o）
| # | 役割 | Pb% | I% | org% |
|---|---|---|---|---|
| 1–4 | 占有 (MO 404–407) | 20.5–25.3 | 74.1–78.4 | 0.6–1.1 |
| 5–16 | 仮想 Pb 6p ×12 | 80.2–85.9 | 13.8–19.4 | 0.2–0.5 |

> 注: pb4 では正準 LUMO の少し上（MO 410,411 など）に Pb 6p 性の軌道も現れるが、
> エネルギー最下の伝導帯（正準 LUMO）は有機局在であり、AVAS は有機混入の少ない
> Pb 6p 群を選び出している。

## 4. 検証（CASCI S0 が README を再現）

本選択の DF-CASCI 基底状態エネルギー S0 と各 `extracted/<sys>/README` の比較:

| 系 | CASCI S0（本選択）| README S0 | 差 | 旧（HOMO/LUMO窓）の差 |
|---|---|---|---|---|
| pb2 | −4317.38113 | −4317.38044 | **−0.69 mHa** | +3.14 mHa |
| pb3 | −6279.87898 | −6279.87843 | **−0.56 mHa** | +5.46 mHa |
| pb4 | −7850.03153 | −7850.03053 | **−1.01 mHa** | +6.07 mHa |

- 全系で **化学精度（1.6 mHa）内**に S0 を再現。占有数の対角も
  `N_Pb 本 ≈1.99 + 3·N_Pb 本 ≈0.003`＝「Pb 価電子 → 空の Pb 6p」描像と一致。
- **限界**: S0 は再現するが、**S1（バンドギャップ）は再現しない**（計算 6.7 eV vs
  README 5.2–5.3 eV）。README の S1 終状態は正準 LUMO より低い relaxed 軌道に対応し、
  その厳密再現には軌道最適化（State-Averaged CASSCF）が必要。本系（nao=744–1320）では
  SA-CASSCF は計算量が非現実的（1 マクロ反復で 70 分超）。**SQD のエネルギー（S0）
  比較用途には本ハミルトニアンで十分**。

## 5. Avogadro での確認方法

`export_orbitals.py` が `analysis/orbitals_avogadro/` に出力する。

### Molden（推奨・1 ファイルで全軌道を閲覧）
```bash
cd analysis
uv run export_orbitals.py ../extracted pb2   # pb3 / pb4 も同様
```
- 出力: `orbitals_avogadro/<sys>_active.molden`
- Avogadro で開き、MO 番号で軌道を切り替える。**MO 番号は本書 §3 の表の # と同じ順**
  （占有 → 仮想 Pb 6p → 除外した正準 LUMO）。
- Pb 6p（仮想）が Pb 上の p ローブ、占有が Pb–I に広がる様子、除外 LUMO が CH₃NH₃ 上に
  局在する様子を直接確認できる。

### cube（等値面が確実に描画される。各軌道 1 ファイル）
```bash
uv run export_orbitals.py ../extracted pb2 --cube --grid 80
```
- 出力: `orbitals_avogadro/<sys>_<NN>_<役割>.cube`
- Avogadro で各 cube を開くと等値面が表示される（大きな系ほど生成に時間がかかる）。
